# 茜 deliver｜デザインガイドライン

調査日：2026年11月11日。390px幅を基準とする初回のデザイン方針案。

## 参照資料とデザインコンセプト

[改善済みヒーロー画像](./改善済みヒーロー画像.png)を全体の視覚基準とする。公開サイトはサービス情報・利用条件・導線の確認に使う。セクションの順序や情報の見せ方は、利用者が依頼の可否を判断する順番に合わせて設計する。 [公開トップページ](https://nx6mbasq.github.io/-deliver/)

**少ない荷物の引越しを、気軽に相談できるサイト。** 親しみやすい写真と短く力強い見出しでサービスを伝え、料金の内訳と利用条件は、申込み前に読み比べやすく示す。利用者が「自分の引越しに合うか」「何を準備するか」「いくらかかりそうか」を順に確認し、無料見積りへ進めるようにする。

### ヒーローから継承する要素

- 白・オフホワイトの広い面と濃紺の日本語見出しで、明るさと読みやすさをつくる。鮮やかなブルーは見出しの要点、主ボタン、リンクに用いる。
- 太い見出し、読みやすい本文、ひときわ大きな価格の数字に強弱がある。各セクションでも、最初に判断に必要な情報が目に入るようにする。
- 自然光のなかでスタッフと利用者が段ボールを受け渡す写真が、共同作業を具体的に伝えている。写真を使う箇所は、作業の理解や人物への信頼につながる場面を選ぶ。
- 淡いブルーの面と線画アイコンを補助に使う。ヒーローの波形や手書き文字、価格の黄色い下線はその場の演出として扱い、以降のセクションでは内容に応じて表現を選ぶ。

## モバイルを基準にした設計

以下は新規セクション向けの初期提案値。色は参照画像の印象に合わせた近似色で、書体・寸法は390px幅での設計値。セクション承認時に確定する。

| 項目 | 初期提案 |
| --- | --- |
| 色 | 白 `#FFFFFF`、オフホワイト `#F7FAFC`、濃紺 `#0D2744`、本文 `#2B415D`、ブランドブルー `#005BC9`、補助面 `#EAF4FC` |
| 書体 | 日本語は Noto Sans JP を候補とする。見出しは太め、本文は標準ウェイト。価格は数字と「円〜」に強弱を付け、適用条件を近くに置く |
| 文字 | セクション見出し 28〜32px、項目見出し 18〜20px、本文 16px、補足 14pxを目安とする。本文の行高は約1.7 |
| 余白 | 左右20pxを基準に本文幅350px。セクション上下48〜64px、関連する項目間16〜24pxを目安とする |
| 操作 | 主要CTAは青地に白文字。タップ領域は44px以上を目安とし、リンクとフォーカスは色以外でも識別できるようにする |
| 幅が広い画面 | 閲覧順は維持し、写真と説明、料金と対応エリアなど、並べて読む意味がある要素を横に配置する。狭い画面や文字拡大時は折り返しで対応する |

料金は罫線で区切った一覧、手順は縦のステップ、利用条件は小見出し付きリスト、FAQは開閉式の質問行を候補とする。条件や料金は実装時にテキストとして扱う前提で設計し、狭い画面でも金額・対象条件・単位の対応が分かるようにする。写真は人物や手元の意味が伝わる位置で切り出す。

## 無料見積り・相談への導線

ヒーローからは既存のWEB見積りフォームへ進める。モバイル下部の導線からは問い合わせ欄へ案内し、そこでWEBと電話を選べる構成を基準とする。フォームの遷移先、電話リンク、既存のセクションリンク、FAQの開閉、荷物メモの操作を各セクションの設計で引き継ぐ。LINEは公開HTML上でリンク先が仮設定のため、正式URLの確認後に有効な導線として扱う。 [問い合わせ欄](https://nx6mbasq.github.io/-deliver/#cta)
