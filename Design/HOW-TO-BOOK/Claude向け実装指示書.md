# ご利用の流れ｜実装指示書

[完成イメージ](./HOW-TO-BOOK-mobile-390.png) と [素材の対応表](./デザイン仕様書.md) に沿って、トップページ `#step` の `.process-art` 画像5点を差し替える。画像の縦横属性は素材に合わせて256とし、直後の見出しが意味を伝えるため `alt=""` を引き継ぐ。

素材に淡いブルーの背景色が含まれている。画像枠に円形のクリップを適用し、枠側の背景色と内側余白は外す。画像枠の寸法は既存のレスポンシブ設定を使い、カード内の配置・文言・順序を維持する。

390px幅でカードの配置と5点の対応を完成イメージと照合し、デスクトップでも画像の見切れやカードの崩れがないことを確認する。
