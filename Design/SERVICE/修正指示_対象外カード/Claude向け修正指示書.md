# Claude向け修正指示書｜SERVICEの対象外欄

[完成イメージ（390px幅）](./完成イメージ_390px.png) に合わせて、トップページの SERVICE 内「対応できない作業・荷物」を修正してください。画像には前後のつながりを示すため、準備欄と「料金と対応エリア」の冒頭も含めています。今回の実装範囲は `index.html` の `#service #restriction` と、この欄に適用するCSSです。

## 変更内容

- 白地に「対応できない作業・荷物」の見出し、カード3枚、詳細リンクを縦に並べます。見出しのアクセント、カードの外枠、詳細リンクの左端をそろえます。
- 現在の分類ラベル「大型」「家電」「作業」を外し、項目名を1枚ずつ表示します。HTMLは順不同リストを使い、既存の `#restriction` を維持してください。
  1. 大型家具・家電
  2. ドラム式洗濯機・有機ELテレビ
  3. 吊り上げ・吊り下げ作業
- 各カードの左に、細い円と短い横線を組み合わせた小さな目印を置きます。目印は装飾として扱い、読み上げから除外します。カードは情報表示用です。
- 「対象外の詳細を見る」のリンク先は `important-notes.html#incompatible` を維持します。既存の青文字・下線・矢印・フォーカス表示を引き継ぎます。

## 390px幅での目安

| 要素 | 指定 |
| --- | --- |
| セクション内の配置 | 左右20px、カード幅350px。準備欄の後に約28px空ける |
| 見出し | 19px、濃紺。左に幅3px・高さ17pxの短い縦線（#9A704B）、文字との間隔8px。見出し下13px |
| カード | 縦一列、間隔8px、高さ48px以上。背景 #FAF8F4、枠線1px #EAE2D6、角丸9px、内側の左右余白13px |
| カード本文 | 15px、行高1.65、#0D2744。左の目印用の列18px、本文までの間隔10px |
| 目印 | 約16pxの円、枠線 #B99D83。中央に幅6pxの横線 #8D694D |
| 詳細リンク | カードの約6px下、リンクのタップ領域は高さ44px以上 |

対象外欄の外側は白地にして、直下の「料金と対応エリア」の水色背景がセクションの切り替わりとして見えるようにします。準備欄や料金セクションのマークアップ・配色は現行の実装を引き継いでください。

## 実装後の確認

- 390px幅で画像と見比べ、カード3枚の左端・目印・文字位置と、料金セクションへのつながりを確認する。
- 狭幅・文字拡大時は項目名が折り返し、カードの高さが内容に応じて伸びることを確認する。
- `#restriction` と詳細リンクの遷移、キーボード操作を確認する。既存のビルド手順に沿って配信用CSSを更新し、既存の検証を実行する。
