# Claude向け SERVICE 実装指示書

[完成イメージ](./SERVICE-mobile-390.png) と [デザイン仕様書](./デザイン仕様書.md) を基準に、承認後の実装作業として公開トップの `index.html` にある `#service` を更新する。このフォルダはデザインの引き継ぎ資料。

1. `index.html` と既存CSS、`package.json` のビルド・検証手順を確認する。既存のセクション階層とCSS構成に合わせて変更箇所を絞る。
2. `#service` に導入、共同作業の写真とキャプション、スタッフ追加の注記、準備、対象外を順に配置する。既存アンカー `#service`、`#duties`、`#restriction` を各対応ブロックで引き継ぐ。完成イメージの上端112pxは既存ヒーローとの接続確認用。
3. 写真は [assets/service-team-photo.png](./assets/service-team-photo.png) を元に、既存サイトの画像配置・最適化方法に沿って登録する。中央の箱と双方の手元が見えるように切り出す。画像に適切な代替テキストと寸法を付ける。見出し、本文、料金、キャプション、リンクはHTMLテキストで実装する。
4. 準備は順序のあるリスト、対象外は分類ラベルと項目が対応する構造で実装する。「準備の詳細を見る」は `important-notes.html#caution`、「対象外の詳細を見る」は `important-notes.html#incompatible` に接続する。スタッフ追加の条件と料金は既存の確認事項と照合する。
5. 390pxを基準に、左右20px、ラベル72px、列間12pxで合わせる。小さい画面と文字拡大時は、本文列の折り返しを許容し、横スクロールが出ないよう確認する。幅が広い画面でも読順を維持し、既存のコンテナと余白に合わせる。
6. リンクのキーボード操作とフォーカス表示、アンカーの到達位置、ヒーローからのつながりを確認する。390pxで完成イメージと照合し、狭幅とデスクトップでも確認する。必要に応じて `npm run build` で配信用CSSを更新し、`npm run check` を実行する。
