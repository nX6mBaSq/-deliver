# Noto Sans JP

Source: Google Fonts CSS2 API, Noto Sans JP, variable weights 400–700.
License: SIL Open Font License 1.1, see OFL.txt.
This locally hosted subset includes public site copy and UI messages. Rebuild with `npm run fonts` after changing copy. Other user-entered characters fall back to system fonts.

The critical and rest WOFF2 files contain disjoint character sets, declared with CSS unicode-range. The critical subset is preloaded for initial headings and navigation. No visitor input is sent to Google Fonts.
